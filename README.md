# Prompt Night — Deck

20-min talk on AI-augmented dev workflows: skills, MCP, SDD frameworks (Spec Kit, Superpowers, GSD, OpenSpec), and the loop of brainstorm → spec → ship.

**Live deck:** https://techlibs.github.io/prompt-night/deck/index-v2.html

## Run locally

```bash
cd deck && python3 -m http.server 8000
# open http://localhost:8000/index-v2.html
```

Press `S` for speaker notes. `?` for shortcuts.

## Contents

- `deck/index-v2.html` — Reveal.js deck (28 slides)
- `deck/theme-v2.css` — Theme
- `deck/assets/` — QR + images
- `docs/superpowers/specs/` — design specs for deck iterations
